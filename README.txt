This is a pipeline project for the GROWER Measurement and Verification Team.
The team is researching methodologies to aggregate county level data into outage level (point level) data with the goal to find one that best approximates this aggregation.
The intent of the pipeline is to have an organized internal tool to implement and test these various methodologies against each other.
